# G2 Two-Way Rubric Coverage Matrix

Each scored rubric criterion and full-marks atom maps to at least one worksheet template field. Conversely, each response field maps to a rubric criterion. The quality modifier is document-level; non-scored worksheet structure maps to submission/integrity checks. Source: participant rubric text copy; page references use inferred form-feed page numbers under K18.

## C. Cross-section dependency checks

1. `A2 → A4 → B1 → B2 → B3 → C3 → D4.2`
2. `B1 membership / pattern → B2, B3, B4, C2 link, C3, C4, D1`
3. `B3 top three → B4, C3, C4, D1 → D2 → D3 → D4 → D5`
4. Any changed figure or assumption must be updated at every location in the ledger's figures/assumptions registers.
5. Any evidence ID must be consistent in each citing field, C1/C2/A3 position and the E1–E8 evidence log.

## D. Coverage acceptance

- All 18 rubric criteria/subcriteria (A1–D5, with D4.1 and D4.2 separate) map to fields above.
- Every full-marks atom is individually mapped in section A.
- Every response field/table is mapped back to its criterion in section B.
- Recommended layout/page guidance is not counted as rubric coverage.
- The quality modifier and unscored compliance structure are mapped as document-level checks, not represented as additional marks.
